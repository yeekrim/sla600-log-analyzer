# sla600-log-analyzer
 
SLA 600 3D 프린터의 공정 로그 파일을 분석하여, 빌드 플레이트·리코터·레진 블럭의 시간대별 위치 변화를 그래프로 시각화하는 Colab 노트북입니다.
 
## 배경
 
SLA 600 장비는 출력 과정에서 빌드 플레이트, 리코터, 레진 블럭의 이동 로그를 텍스트 파일로 기록합니다. 하지만 이 로그는 raw 텍스트 형태로만 제공되어 공정 상태를 한눈에 파악하기 어렵습니다.
 
K-DIVA에서 다른 장비(M160)의 머신로그를 산소농도·압력·온도 등 시간별 그래프로 시각화해 보여주는 사례를 참고하여, SLA 600의 로그 데이터에도 동일한 방식의 시각화를 적용해 보았습니다.
 
## 목적 및 의의
 
raw 로그 텍스트만으로는 장비가 정상적으로 동작했는지 한눈에 판단하기 어렵습니다. 축별 위치 변화를 시간에 따라 시각화하면 다음과 같은 활용이 가능합니다.
 
- **비정상 움직임 포착**: 정상 패턴(예: 서포터 생성 구간의 규칙적인 상하 왕복)에서 벗어나는 구간을 그래프상에서 시각적으로 빠르게 발견할 수 있습니다.
- **역추적을 통한 원인 분석**: 이러한 시각화 자료가 로그 단위로 누적되면, 이상 발생 시점의 그래프 패턴을 과거 데이터와 비교하여 원인을 역으로 추적하는 근거 자료로 활용할 수 있습니다.
즉, 이 노트북은 단순 시각화를 넘어 장비 이상 탐지와 사후 원인 분석을 위한 기초 데이터 축적 도구로서의 의의를 갖습니다.
 
## 주요 기능
 
- 로그 파일에서 키워드(`Axis 0`, `Axis 1`, `Before`/`After` 등) 기반으로 축별 로그 라인 필터링
- 정규식으로 타임스탬프와 위치(Position) 값 추출
- 축별(빌드 플레이트 / 리코터 / 레진 블럭) 위치를 시간에 따른 라인 그래프로 시각화
- 레진 레벨(Current Position)과 타겟 레진 레벨(Target Level)을 함께 그려 목표값과의 격차 확인
## 시각화 결과
 
| 항목 | 설명 |
| --- | --- |
| Axis 0 (빌드 플레이트) | 적층이 진행될수록 위치값 증가, 서포터 생성 구간에서 상하 왕복 패턴 확인 가능 |
| Axis 1 (리코터) | 기포 제거를 위해 빌드 플레이트 위를 왕복하는 패턴 확인 |
| Axis 2 (레진 블럭) | Before/After 위치 변화로 레진 수위 조절 동작 확인 |
| Resin Level | 현재 레진 레벨과 타겟 레벨의 시간별 격차 확인 |
 
## 사용 방법
 
1. Google Colab에서 노트북을 엽니다.
2. Google Drive를 마운트합니다.
3. `log_file_path` 변수에 분석하려는 SLA 600 로그 파일 경로를 지정합니다.
```python
   log_file_path = '/content/drive/MyDrive/SLA/your_log_file.log'
```
 
4. 전체 셀을 순서대로 실행하면 축별 시계열 그래프가 출력됩니다.
`log_file_path`만 교체하면 동일한 로그 포맷을 가진 다른 SLA 600 출력 로그에도 바로 적용할 수 있습니다.
 
## 기술 스택
 
- Python (Google Colab)
- pandas / re (로그 파싱)

## 제한 사항 및 개선 아이디어
 
- 현재는 노트북 셀 단위 실행 구조로, 함수화(`parse_log()`, `plot_axis()` 등)를 통해 재사용성을 높일 수 있습니다.
- 로그 포맷이 변경될 경우 필터링 키워드와 정규식 패턴을 함께 수정해야 합니다.
- 축별 그래프를 하나의 대시보드로 통합하면 공정 전체를 한눈에 보기 쉬워집니다.
