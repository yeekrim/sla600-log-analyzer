# sla600-log-analyzer
 
SLA 600 3D 프린터의 공정 로그 파일을 분석하여, 빌드 플레이트·리코터·레진 블럭의 시간대별 위치 변화를 그래프로 시각화하는 Python 스크립트입니다.
 
## 배경
 
SLA 600 장비는 출력 과정에서 빌드 플레이트, 리코터, 레진 블럭의 이동 로그를 텍스트 파일로 기록합니다. 하지만 이 로그는 raw 텍스트 형태로만 제공되어 공정 상태를 한눈에 파악하기 어렵습니다.
 
K-DIVA에서 다른 장비(M160)의 머신로그를 산소농도·압력·온도 등 시간별 그래프로 시각화해 보여주는 사례를 참고하여, SLA 600의 로그 데이터에도 동일한 방식의 시각화를 적용해 보았습니다.
 
## 목적 및 의의
 
raw 로그 텍스트만으로는 장비가 정상적으로 동작했는지 한눈에 판단하기 어렵습니다. 축별 위치 변화를 시간에 따라 시각화하면 다음과 같은 활용이 가능합니다.
 
- **비정상 움직임 포착**: 정상 패턴(예: 서포터 생성 구간의 규칙적인 상하 왕복)에서 벗어나는 구간을 그래프상에서 시각적으로 빠르게 발견할 수 있습니다.
- **역추적을 통한 원인 분석**: 이러한 시각화 자료가 로그 단위로 누적되면, 이상 발생 시점의 그래프 패턴을 과거 데이터와 비교하여 원인을 역으로 추적하는 근거 자료로 활용할 수 있습니다.
즉, 이 도구는 단순 시각화를 넘어 장비 이상 탐지와 사후 원인 분석을 위한 기초 데이터 축적 도구로서의 의의를 갖습니다.
 
## 주요 기능
 
- 로그 파일에서 키워드(`Axis 0`, `Axis 1`, `Before`/`After` 등) 기반으로 축별 로그 라인 필터링
- 정규식으로 타임스탬프와 위치(Position) 값 추출
- 축별(빌드 플레이트 / 리코터 / 레진 블럭) 위치를 시간에 따른 라인 그래프로 시각화
- 레진 레벨(Current Position)과 타겟 레진 레벨(Target Level)을 함께 그려 목표값과의 격차 확인
- **설정 기반 파싱**: 필터 키워드와 정규식을 `CONFIG`(`TIMESTAMP`, `AXES`) 한 곳에 모아, 로그 포맷 변경 시 코드가 아닌 설정만 수정
- **함수화**: `parse_log()`, `extract_series()`, `plot_axis()`, `plot_dashboard()` 로 로직을 분리해 재사용성 확보
- **통합 대시보드**: 모든 축을 하나의 그림으로 합쳐 공정 전체를 한눈에 확인
## 시각화 결과
 
| 항목 | 설명 |
| --- | --- |
| Axis 0 (빌드 플레이트) | 적층이 진행될수록 위치값 증가, 서포터 생성 구간에서 상하 왕복 패턴 확인 가능 |
| Axis 1 (리코터) | 기포 제거를 위해 빌드 플레이트 위를 왕복하는 패턴 확인 |
| Axis 2 (레진 블럭) | Before/After 위치 변화로 레진 수위 조절 동작 확인 |
| Resin Level | 현재 레진 레벨과 타겟 레벨의 시간별 격차 확인 |
 
## 사용 방법

의존성 설치 후 로그 파일 경로를 인자로 넘겨 실행합니다.

```bash
pip install pandas matplotlib
```

- 통합 대시보드(기본):

```bash
python sla_movement_graph.py /path/to/your_log_file.log
```

- 축별 개별 그래프:

```bash
python sla_movement_graph.py your_log_file.log --individual
```

- 화면 표시 대신 이미지로 저장:

```bash
python sla_movement_graph.py your_log_file.log --save out.png
```

로그 파일 경로만 바꾸면 동일한 로그 포맷을 가진 다른 SLA 600 출력 로그에도 바로 적용할 수 있습니다.
로그 포맷 자체가 다르면 스크립트 상단의 `CONFIG`(`TIMESTAMP`, `AXES`)만 수정하면 됩니다.

`parse_log()` · `extract_series()` · `plot_axis()` · `plot_dashboard()` 함수를 다른 코드에서 직접 import 해 재사용할 수도 있습니다.

그래프 한글 라벨은 레포에 함께 배포한 `fonts/NanumGothic-Regular.ttf`(OFL 라이선스)를 자동 등록해 렌더링하므로, 시스템에 한글 폰트가 없어도 어디서든 동일하게 표시됩니다.

## 기술 스택

- Python 3
- pandas / re (로그 파싱)
- matplotlib (시각화, NanumGothic 폰트 번들)
## 개선 사항 (적용 완료)

아래는 초기 버전의 제한 사항으로, 현재 노트북에 모두 반영되었습니다.

- ✅ **함수화**: 셀 단위 반복 코드를 `parse_log()`, `extract_series()`, `plot_axis()`, `plot_dashboard()` 로 분리해 재사용성을 높였습니다.
- ✅ **포맷 변경 대응**: 필터링 키워드와 정규식 패턴을 `CONFIG` 셀(`TIMESTAMP`, `AXES`) 한 곳에 모아, 로그 포맷이 바뀌어도 코드가 아닌 설정만 수정하면 됩니다.
- ✅ **통합 대시보드**: `plot_dashboard()` 로 축별 그래프를 하나의 대시보드로 통합해 공정 전체를 한눈에 볼 수 있습니다.

### 향후 개선 아이디어

- 정상 패턴 대비 이상 구간 자동 하이라이트(임계값/규칙 기반 탐지)
- 여러 로그 파일 일괄 처리 및 결과 비교
- 추출한 시계열을 CSV/Parquet로 내보내 데이터 축적
